# 重装机兵 · 浏览器版 & 全地图集

用 jsnes 模拟器内核在浏览器里直接运行原版 FC ROM（mapper 74 / MMC3），并附带从 ROM 地图表导出的全地图集。

## 内容

| 路径 | 说明 |
|---|---|
| `index.html` | 站点首页 |
| `game/` | 游戏本体，单文件 HTML（1.2 MB，ROM 内嵌，离线可玩） |
| `atlas/` | 240 张地图 PNG + 浏览页 `index.html` + `目录.csv` |
| `.nojekyll` | 关闭 Jekyll 处理，保证中文文件名正常访问 |

## 操作

方向键移动 · `Z` 确认 · `X` 取消 · `Enter` 开始。首次进入需取名字：方向键选字，`Z` 输入，`GO` 提交。

## 地图集

- `000_世界地图.png`：4096×4096，每格 16px。
- `001..239_名称.png`：ROM 地图 ID 即编号，文件名带名称。
- 渲染链与游戏引擎一致：格子字节 → 组合组×64 + 序号 → 按地图调色板与 CHR bank 取 variant → 全局图块表 → 图集坐标。
- 无名民宅按出入口连通关系推定归属命名（如 `009_拉多·房屋02`）。
